💡 Gợi Ý Cấu Trúc Trả Lời Chuẩn STAR (10/10)

IT Rubric
1. Situation (Bối cảnh):

Trong đồ án môn học viết ứng dụng đọc ghi file cấu hình JSON và kết nối cơ sở dữ liệu JDBC.

2. Task (Nhiệm vụ):

Cần đảm bảo chương trình không bị crash đột ngột khi file cấu hình bị xoá hoặc kết nối mạng bị ngắt giữa chừng.

3. Action (Hành động kỹ thuật cụ thể):

Sử dụng Checked Exception (như IOException, SQLException) buộc xử lý hoặc throws lên lớp trên, kết hợp try-with-resources để tự động giải phóng connection. Với NullPointerException thì kiểm tra validation tham số đầu vào thay vì lạm dụng try-catch.

4. Result (Kết quả đo lường):

Ứng dụng hoạt động bền bỉ, log lỗi rõ ràng (Stack Trace và Error Code chuẩn), không để rò rỉ tài nguyên bộ nhớ.

⚠️ 2 Cái Bẫy Giám Khảo Thường Xoáy:

  • Bẫy 1: Viết khối catch (Exception e) {} rỗng (Swallow Exception), làm biến mất nguyên nhân gốc của lỗi.
  • Bẫy 2: Ném Throwable hoặc lạm dụng RuntimeException cho mọi tình huống nghiệp vụ thông thường.

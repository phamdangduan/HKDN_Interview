## 🎯 2. MA TRẬN 4 CẤP BẬC KỸ THUẬT (IT HIERARCHY LEVELS)

Hệ thống AI Engine của TalentAI được thiết kế và huấn luyện đặc thù cho **4 cấp bậc phát triển của Kỹ sư Phần mềm**:

| Cấp Bậc | Đối Tượng Mục Tiêu | Trọng Tâm Khảo Hạch Kỹ Thuật | Tiêu Chí Đánh Giá Chuẩn STAR |
| :--- | :--- | :--- | :--- |
| 🟢 **Intern** | Sinh viên năm 3-4, chuẩn bị thực tập | **CS Fundamentals & Tư duy nền tảng:** OOP 4 tính chất, Collections Framework, Exception Handling (Checked vs Unchecked), Git workflow cơ bản, khả năng tiếp thu và giải thích logic mã nguồn. | Không đòi hỏi kinh nghiệm production. Đánh giá cao tư duy mạch lạc, sự trung thực và tinh thần học hỏi. |
| 🔵 **Fresher** | Mới tốt nghiệp / < 1 năm kinh nghiệm | **Làm chủ 1 Tech Stack cốt lõi:** Thiết kế RESTful API chuẩn, vòng đời HTTP, kết nối RDBMS (MySQL/PostgreSQL), ORM (JPA/Hibernate), đánh index cơ bản, bảo vệ đồ án tốt nghiệp, Clean Code & Unit Test. | Trả lời rõ vai trò cá nhân trong đồ án, giải thích cơ chế bảo vệ giao dịch (Transaction ACID) và test coverage. |
| 🟣 **Junior** | 1 - 2.5 năm kinh nghiệm thực chiến | **Bài toán Production & Chịu tải:** Xử lý bất đồng bộ, Race Condition, Deadlock, tối ưu truy vấn SQL chậm, phân vùng dữ liệu, Redis Caching, RabbitMQ/Kafka, Mocking/Integration Test, On-call xử lý sự cố. | Đòi hỏi số liệu thực tế đo lường (RPS, Latency p99, Memory usage), lập luận phản biện sắc bén khi bị hỏi xoáy. |
| 🟠 **Mid-Level** | 3+ năm kinh nghiệm | **System Design & Architecture:** Phân tách Microservices, High Availability, Database Sharding, Event-driven architecture, bảo mật hạ tầng và cân bằng trade-offs giữa chi phí - hiệu năng. | Khả năng thiết kế hệ thống quy mô lớn, dẫn dắt giải pháp kỹ thuật và ra quyết định kiến trúc. |

## 💻 3. CÁC MẢNG KỸ THUẬT CHUYÊN SÂU (TECH TRACKS)

TalentAI hỗ trợ các lộ trình phỏng vấn chuẩn hóa cho các chuyên ngành IT:
1. **Backend Track:** Java (Spring Boot), Node.js (NestJS/Express), Python (FastAPI/Django), Go, .NET.
2. **Frontend Track:** React, Next.js, Vue, TypeScript, Tailwind CSS, Web Vitals, Performance Optimization.
3. **Fullstack Track:** Phối hợp kiến trúc Frontend - Backend, REST API, WebSocket, DB Design.
4. **Mobile Track:** Flutter, React Native, Swift (iOS), Kotlin (Android).
5. **DevOps & Cloud Track:** Docker, Kubernetes, CI/CD Pipeline (GitHub Actions/GitLab CI), AWS/GCP, Terraform, Monitoring (Prometheus/Grafana).
6. **AI & Data Track:** Data Pipeline, SQL/NoSQL, Machine Learning Model Deployment, Vector DB, RAG.

## 🎓 4. PHÂN HỆ 1: ỨNG CỬ VIÊN IT TỰ LUYỆN TẬP THỰC CHIẾN (B2C)

### Luồng trải nghiệm 6 bước của Lập trình viên:
1. **Dashboard Trung Tâm ([`candidate/dashboard.html`](file:///e:/Minh/candidate/dashboard.html)):** Theo dõi lịch sử điểm STAR, chuỗi ngày rèn luyện và tiến độ chuẩn bị phỏng vấn.
2. **Setup Phòng Phỏng Vấn Kỹ Thuật ([`candidate/setup.html`](file:///e:/Minh/candidate/setup.html)):**
   - Chọn Cấp bậc mục tiêu (🟢 Intern / 🔵 Fresher / 🟣 Junior / 🟠 Mid-Level).
   - Chọn Tech Track và tải CV IT hoặc bấm *⚡ Dùng CV mẫu theo cấp bậc*.
   - Nhập JD công ty mong muốn hoặc dùng ô Chat Prompt kỹ thuật (Ví dụ: *"Phỏng vấn vị trí Java Backend Junior, xoáy sâu vào xử lý Deadlock trong MySQL và tối ưu bộ nhớ JVM"*).
3. **Phòng Phỏng Vấn Trực Tiếp 1-1 ([`candidate/mock_room.html`](file:///e:/Minh/candidate/mock_room.html)):**
   - Đối thoại giọng nói 2 chiều với Giám khảo AI Avatar (Alex Chen - Java Architect, Sarah Jenkins - Cloud Architect).
   - Động cơ **Adaptive Next Turn** lắng nghe câu trả lời của ứng viên, tự động phát hiện số liệu mập mờ để đặt câu hỏi xoáy (Probing) bám sát cấp bậc.
4. **Báo Cáo Thẩm Định STAR Chi Tiết ([`candidate/report_detail.html`](file:///e:/Minh/candidate/report_detail.html)):**
   - Điểm số 4 tiêu chí STAR: Tình huống (S), Nhiệm vụ (T), Hành động kỹ thuật (A), Kết quả đo lường (R).
   - Bản đồ lỗ hổng kỹ thuật chỉ rõ điểm yếu (ví dụ: *Hổng kiến thức về Transaction Isolation Levels*).
   - Tính năng **AI Rewrite**: Sinh câu trả lời mẫu 10/10 chuẩn kỹ thuật để ứng viên học hỏi.
5. **Quick Drill Room 3 Phút ([`candidate/drill_room.html`](file:///e:/Minh/candidate/drill_room.html)):**
   - Chọn cấp bậc (Intern / Fresher / Junior) để luyện phản xạ cấp tốc đúng câu hỏi hóc búa vừa bị điểm thấp, xem STAR cheat sheet và các bẫy thường gặp.
6. **CV & Cover Letter Studio ([`candidate/cv_studio.html`](file:///e:/Minh/candidate/cv_studio.html)):**
   - So khớp độ tương thích ATS với JD IT theo từng cấp bậc.
   - Tự động sinh Thư ứng tuyển (Cover Letter) chuẩn kỹ thuật làm nổi bật câu chuyện giải quyết bài toán thực tế.

## 🏢 5. PHÂN HỆ 2: DOANH NGHIỆP CÔNG NGHỆ TUYỂN DỤNG TỰ ĐỘNG (B2B)

*(Dành cho các doanh nghiệp phần mềm như FPT Software, Viettel, VNG, VNPT, v.v.)*

### Luồng tuyển dụng kỹ thuật tự động hóa:
1. **Thiết Lập Chiến Dịch Vetting ([`enterprise/campaign_creator.html`](file:///e:/Minh/enterprise/campaign_creator.html)):**
   - Chọn cấp bậc tuyển dụng (Intern / Fresher / Junior) và Tech Track.
   - Dùng mẫu điền nhanh JD IT (Java Intern F-Ville, Fresher React, Junior Microservices, Mid DevOps).
   - Cài đặt ngưỡng điểm đạt **Cut-off Score** (ví dụ: $\ge$ 80 điểm) và mức độ hỏi xoáy đối kháng.
   - Hệ thống tự động sinh link mời ứng viên và mẫu bài đăng tuyển dụng Facebook / LinkedIn.
2. **Ứng Viên Nộp CV & Tham Gia Khảo Hạch ([`candidate/apply.html`](file:///e:/Minh/candidate/apply.html)):**
   - Ứng viên nộp CV qua link chiến dịch $\rightarrow$ AI quét độ khớp CV (ATS) $\rightarrow$ Bước vào bài phỏng vấn 1-1 với Giám khảo AI Avatar.
3. **Bảng Ma Trận Lọc Tự Động ([`enterprise/portal.html`](file:///e:/Minh/enterprise/portal.html)):**
   - Bộ lọc kép theo trạng thái (Đạt Cut-off / Chưa đạt) và Cấp bậc (Intern / Fresher / Junior).
   - Hiển thị bảng xếp hạng điểm STAR, mức độ kháng hỏi xoáy và tỷ lệ khớp ATS.
   - Tính năng gửi Email 1-click: Gửi thư mời Vòng 2 cùng Tech Lead hoặc thư góp ý phát triển kèm hồ sơ lưu Talent Pool.
4. **Hồ Sơ Thẩm Định Chi Tiết ([`enterprise/candidate_dossier.html`](file:///e:/Minh/enterprise/candidate_dossier.html)):**
   - **Thẻ Kiểm Tra Đối Soát Cấp Bậc (Level Alignment & Risk Audit):** Đánh giá ứng viên có khai khống CV hay không, phân tích năng lực thực tế so với cấp bậc đăng ký.
   - Nghe lại đoạn ghi âm (Audio Replay) các câu trả lời kỹ thuật quan trọng của ứng viên trước khi ra quyết định tuyển dụng.

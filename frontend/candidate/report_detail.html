Trích dẫn câu trả lời của bạn:

“HashMap lưu dữ liệu dưới dạng Node key-value trong mảng bucket. Khi gọi put(), Java tính hash từ key.hashCode() rồi dùng phép bit (n - 1) & hash để tìm index bucket. Khi xảy ra trùng lặp index (Hash Collision), các Node được liên kết dạng LinkedList. Từ Java 8, để tránh suy giảm hiệu năng từ O(1) về O(n) khi bucket có quá nhiều phần tử, nếu độ dài danh sách vượt ngưỡng TREEIFY_THRESHOLD là 8 và mảng có ít nhất 64 bucket, Java sẽ tự động chuyển đổi danh sách liên kết sang Cây Đỏ Đen (Red-Black Tree), giúp độ phức tạp tìm kiếm giảm xuống chỉ còn O(log n).”
